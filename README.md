# «Кассета» — прототип: бой + обвязка (этапы 2-4)

Godot 4.3. Всё на плейсхолдерах: персонажи — цветные прямоугольники, арт не генерился.
Задача этапа — проверить, что петля боя ощущается хорошо, до траты денег на генерацию.

## Как запустить

1. Скачать Godot 4.3 (или 4.4) — версия Standard, не .NET.
2. Открыть Godot → Import → выбрать файл `project.godot` в этой папке → Import & Edit.
3. Нажать F5 (или кнопку ▶ вверху справа).

Проверка на телефоне: Project → Export → Android. Либо просто гонять на ПК —
управление продублировано клавишами.

## Управление

| Действие | Телефон | Клавиатура |
|---|---|---|
| Удар (3 тапа = комбо) | тап | Пробел |
| Тяжёлый удар | удержание и отпустить | F (удерживать) |
| Уклон | свайп вниз | S |
| Блок | свайп влево | A |
| Препятствие | свайп вверх | W |
| Фаталити | кнопка справа | E |
| Ярость | кнопка справа | R |

## Вид

Три четверти: земля — уходящая вдаль плоскость, у персонажей своя глубина,
масштаб и тень. Зомби приходят кучками по 2-4 с одной стороны, занимают разные
дорожки по глубине и расталкиваются, чтобы не сливаться в один прямоугольник.

## Бой

- Толпа заходит с двух сторон. Тап по правой/левой половине — удар в эту сторону.
- Четыре класса оружия с разным ритмом: лопата (медленно, сносит группу тяжёлым),
  вилы (дистанция, протыкают двоих), мачете (быстрая серия из пяти), обрез
  (дальний, два патрона и перезарядка).
- Телеграф атаки: голубой — парируется, красный — только уклон.
- Идеальное парирование сбивает зомби, копит ярость и шкалу добивания.
- Замах сбивается только тяжёлым или завершающим ударом серии — мелкие тычки
  больше не отменяют чужую атаку.
- Добивание не даётся за каждого: копится за чистую игру, бьёт по площади страхом.
- Комбо-счётчик поднимает монеты до ×3, сбрасывается при получении урона.
- Отдача: хитстоп на тяжёлых ударах, тряска камеры, цифры урона.

## Шрифты

Rubik Wet Paint — заголовки (потёки краски, мультяшность в духе Рика и Морти).
Rubik Black / Bold / Medium — всё остальное. Одна семья, кириллица родная.
Лежат в `fonts/`, грузятся в рантайме через `scripts/fonts.gd`: preload не годится,
так как .ttf требует импорта редактором, а проект должен запускаться и напрямую.

## Экраны

- **Хаб** — прогресс главы, надетое снаряжение, статистика, кнопка «Продолжить», нижняя навигация.
- **Карта уровней** — главы с переключением, сетка уровней, звёзды, боссы, замки; открывается на текущей главе.
- **Магазин** — вкладки Оружие / Броня / Расходники / Приёмы. 20 стволов, 5 уровней прокачки каждый,
  6 комплектов брони, 4 расходника, 10 приёмов добивания.
- **Снаряжение** — что куплено, что надето, смена оружия/брони/приёма.
- **Задания** — 12 ачивок с полосами прогресса и наградами в кристаллах; часть открывает приёмы.
- **Сборы перед боем** — уровень, цена в энергии, снаряжение, расходники, кнопка «В бой».
- **Итоги** — звёзды (пройти / без урона / комбо 30), монеты за бой и награда, статистика забега.

## Что уже работает

- Автоходьба деда, параллакс из трёх слоёв.
- Генератор уровней: детерминированный по номеру уровня, ячейки волна / препятствие / передышка,
  обучающие первые три уровня главы, «мясной» каждый пятый, босс каждый двадцатый.
- 5 типов зомби + 3 босса, у каждого свои цифры и сопротивление оглушению.
- Оглушение считается от доли снятого здоровья — зомби гарантированно успевает оглушиться
  до смерти, иначе фаталити не срабатывало бы никогда (это была реальная ошибка, поймана тестом).
- Фаталити: даёт ×3 монет и +25 % ярости. Это основной источник дохода: бот-тест собирает
  244 монеты с фаталити против 61 без них.
- Ярость: 6 секунд двойного урона и неуязвимости.
- Смерть, экран проигрыша, воскрешение (реклама-заглушка), повтор без траты энергии.
- Энергия: 10 единиц, уровень 1, босс 2, восстановление 1 за 8 минут, сохраняется между запусками.
- Сохранение в `user://kasseta_save.json`: монеты, кристаллы, прогресс, энергия.

## Чего ещё нет

Магазина, оружия кроме базового, брони, аптечек, катсцен, ачивок, рекламы и покупок,
бесконечной дороги, звука. Всё это следующие этапы.

## Автотест

`test.tscn` — бот проходит уровень, умирает, воскресает, добивает босса и проверяет
детерминизм генератора. Запуск без окна:

```
godot --headless --path . res://test.tscn
```

## Структура

```
project.godot        настройки, автозагрузка Data
main.tscn            игровая сцена
scripts/game.gd      петля уровня, ввод, интерфейс, параллакс
scripts/player.gd    дед: боевые состояния, урон, ярость
scripts/enemy.gd     зомби: типы, оглушение, атаки
scripts/levelgen.gd  генератор уровней
scripts/data.gd      сохранение, монеты, энергия
test.gd / test.tscn  автотест
```
